# javTex

**javTex** is a cross-platform LaTeX editor written in Java. It aims to provide a simple, lightweight environment for writing LaTeX documents, compiling them, and viewing the resulting PDFs in one application.

## Features

* **LaTeX text editor** — syntax highlighting, line numbers, code folding, and macros, powered by [RSyntaxTextArea](https://github.com/bobbylight/RSyntaxTextArea).
* **File management** — create, open, and save `.tex` documents, with prompts to prevent accidental loss of unsaved changes.
* **LaTeX compilation** — compile documents using an external `pdflatex` installation and view compiler output in the application.
* **Integrated PDF viewer** — display compiled PDFs alongside the editor, with scrolling and multi-page support.
* **Maven build system** — manage dependencies and package the application.

## Requirements

To build and run javTex from source, you need:

* Java Development Kit (JDK) 21 or newer.
* [Apache Maven](https://maven.apache.org/).
* A LaTeX distribution that provides `pdflatex`, such as [TeX Live](https://www.tug.org/texlive/) or [MiKTeX](https://miktex.org/).

The LaTeX distribution must be installed separately and `pdflatex` must be accessible through your system's `PATH`.

Some LaTeX documents require additional packages that may not be included in a minimal TeX installation.

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/bozmoss/javTex.git
cd javTex
```

### 2. Build the application

Run:

```bash
mvn clean package
```

Maven will compile the source code, resolve dependencies, and package the application.

### 3. Run javTex

```bash
java -jar target/javTex-0.1.0-SNAPSHOT.jar
```

The packaged JAR includes the application's Maven dependencies.

### 4. Compile a LaTeX document

1. Open javTex.
2. Create a new document or open an existing `.tex` file.
3. Write your LaTeX source.
4. Save the document.
5. Select **File → Compile**.
6. View the compiler output in the build log and the generated PDF in the viewer.

Compiled PDFs are generated in the same directory as the corresponding `.tex` file.

* `src/main/java/com/javtex/latex/Main.java` — application entry point.
* `src/main/java/com/javtex/latex/ui/MainWindow.java` — main application window and build log.
* `src/main/java/com/javtex/latex/ui/Menu.java` — menus and document file operations.
* `src/main/java/com/javtex/latex/compiler/Compiler.java` — runs the external LaTeX compiler and captures its output.
* `src/main/java/com/javtex/latex/pdf/PDFViewer.java` — embeds ICEpdf's PDF document viewer.
* `pom.xml` — Maven configuration, dependencies, and packaging.

The `target/` directory is generated by Maven and does not need to be committed to Git.

## Platform Compatibility

javTex is designed with cross-platform support in mind.

* **Windows:** requires a Windows-compatible Java runtime and a LaTeX distribution such as MiKTeX or TeX Live.
* **Linux:** requires a compatible Java runtime and a LaTeX distribution such as TeX Live.

The application can be built from the same Java source code on supported platforms. Native installers and platform-specific packaging may require separate builds.

## Current Limitations

javTex is under active development. Current limitations include:

* Compilation requires an external `pdflatex` installation.
* The available LaTeX packages depend on the user's TeX distribution.
* The PDF viewer currently renders pages as images and provides basic scrolling.
* Advanced editor features such as command completion, SyncTeX navigation, and clickable compiler errors are not yet implemented.
